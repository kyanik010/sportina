# SportivTV — تطبيق IPTV رياضي عربي

تطبيق IPTV رياضي لنظام Android TV والهواتف. اللغة الأساسية للتطبيق عربية، ويستهدف أجهزة ARM64.

## المعمارية الحالية

- **Media3 / ExoPlayer:** جلسة تشغيل الفيديو الأساسية.
- **Media3 audio-only session:** جلسة منفصلة لمصدر التعليق الخارجي مع تعطيل مسار الفيديو فيها؛ لا يتم فك ترميز فيديو القناة الصوتية.
- **OkHttp:** طبقة الاتصال HTTP.
- **M3U / M3U8:** تحليل قوائم القنوات.
- **XMLTV / EPG:** قراءة دليل البرامج عند توفره.

> تنبيه: الصوت الخارجي ما زال بحاجة إلى اختبارات على روابط بث حقيقية. الجلسة الصوتية المنفصلة لا تضمن وحدها مزامنة مثالية بين قناتين مباشرتين، لأن توقيت البث قد يختلف بين المصدرين.

## البناء

### المتطلبات

- JDK 17
- Android SDK Platform 35
- Android Gradle Plugin 8.7.2
- Gradle Wrapper 8.12

لا ترفع ملف `local.properties`؛ أنشئه محليًا من Android Studio أو حدّد مسار SDK في بيئة البناء.

### أوامر البناء

Windows PowerShell:

```powershell
.gradlew.bat assembleDebug
.gradlew.bat assembleRelease
.gradlew.bat test
```

Linux / macOS:

```bash
./gradlew assembleDebug
./gradlew assembleRelease
./gradlew test
```

## معمارية الإصدار

إعداد Gradle الحالي يقيّد ملفات APK بمعمارية **arm64-v8a** فقط. لا يتضمن الإصدار ARMv7 أو x86_64.

الناتج المتوقع:

```
app/build/outputs/apk/debug/app-debug.apk
app/build/outputs/apk/release/app-release.apk
```

يجب فحص APK الناتج بعد البناء للتأكد من أن مكتباته الأصلية — إن وجدت — تخص ARM64 فقط.

## اختبار الصوت الخارجي

- اختيار قناة ثانية من قائمة القنوات كمصدر للتعليق.
- تعطيل مسار الفيديو في جلسة الصوت الخارجية.
- عدم كتم صوت الفيديو الأساسي إلا بعد جاهزية مسار صوت خارجي فعلي.
- إعادة مستوى صوت الفيديو السابق عند إيقاف الصوت الخارجي أو فشله.
- التحكم اليدوي في الإزاحة يعمل فقط عندما يوفر مصدر الصوت خطًا زمنيًا قابلًا للبحث.

لم يتم الادعاء بأن مزامنة القناتين مثالية أو أن الميزة اجتازت اختبارات بث طويلة. يلزم اختبارها على HLS وMPEG-TS ومزودين وأجهزة مختلفة.

## الأمان

- لا تحفظ كلمات المرور أو مفاتيح الإدارة في المستودع.
- لا ترفع `local.properties` أو ملفات التوقيع أو ملفات الأسرار.
- خزّن بيانات الاشتراكات محليًا باستخدام آلية التخزين الآمن المعتمدة في التطبيق.
