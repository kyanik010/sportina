# SportivTV - تقرير الإصدار النهائي
## الإصدار 1.0.0

---

## نظرة عامة

تطبيق IPTV رياضي عربي فاخر لـ Android TV والهواتف، مبني على ExoPlayer/Media3.

**معماريات APK**: arm64-v8a (أساسي)، armeabi-v7a، x86_64، universal
**أقل إصدار Android**: 5.0 (API 21)
**اللغة الافتراضية**: العربية (RTL)
**محرك الفيديو**: ExoPlayer/Media3 1.2.1

### ⚠️ قيود تقنية معروفة

1. **الصوت الخارجي (تجريبي)**: 
   - يعمل فقط مع بثوث MPEG-TS/HLS القياسية
   - لا يدعم البثوث المشفرة
   - لا يدعم DASH (.mpd)
   - استخراج PCM مبسط (لا يفك تشفير AAC/MP3 بالكامل)
   - الدقة تعتمد على خصائص البث

2. **EPG**: 
   - يعتمد كليًا على توفير رابط XMLTV من المزود
   - بعض المزودين لا يوفرون EPG

3. **مزامنة الصوت**: 
   - لا يمكن ضمان مزامنة مثالية لكل البثوث
   - الإزاحة اليدوية [-1000ms, +1000ms] متاحة

4. **استهلاك الذاكرة**: 
   - التطبيق يستخدم largeHeap للتعامل مع قوائم القنوات الكبيرة
   - قد يحتاج تحسينًا للأجهزة منخفضة المواصفات

5. **بناء APK**: 
   - يتطلب JDK 17 و Android SDK 34
   - Gradle 8.5

### اختبارات البث الحقيقي
**الحالة**: لم تُجرَ بعد (تتطلب اشتراك IPTV حقيقي)

**المطلوب اختباره**:
1. تشغيل قناة HLS (.m3u8) حقيقية
2. تشغيل قناة TS (.ts) حقيقية
3. تبديل سريع بين 10 قنوات
4. إعادة اتصال بعد قطع الشبكة
5. الصوت الخارجي على بث حقيقي
6. EPG مع مزود حقيقي
7. أداء على Android TV box (ARM64)

### نتائج البناء
**الحالة**: لم يُبنَ بعد في هذه الجلسة (يتطلب بيئة Android SDK)

**التعليمات**:
```bash
cd IPTV
./gradlew assembleRelease
```
الملف الناتج: `app/build/outputs/apk/release/SportivTV-v1.0.0-arm64-v8a.apk`
